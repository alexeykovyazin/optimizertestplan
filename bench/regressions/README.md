# Храповик (принцип 5, раздел 8.1)

Каждая найденная регрессия становится постоянным тестом `*.json`
(формат — docstring в bench/harness/ratchet.py). Проверка дешёвая:
по плану (plan_required / plan_forbidden) и по счётчикам (counters_max).
Исполнение по времени — только для храповика с эталонным временем < 1 с.

Запись о сознательно принятой регрессии кладётся в bench/accepted/
(поля: query_id, max_r, reason, author, expires) — гейт её не блокирует,
отчёт показывает отдельно (раздел 9).
