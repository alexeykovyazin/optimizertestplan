Пятое ревью оптимизатора v5.0-impr-opt

Исправления ревью 08.11 работают: V1–V5 и V8–V12 закрыты тестами. Но 36 новых коммитов добавили три ошибки уровня critical: outer hash join теряет условие ON, BHJ останавливает сервер, LIKE с ESCAPE даёт 0 строк.

36 коммитов база сравнения a3cfa97218 сборка Windows x64 от 12.11, embedded isql; CEB — не замерен новые находки W1–W20, вне ветки X1–X3

1Главное

  • Исправления 08.11 работают. Тесты 31–34 дают верные числа (V1, V2, V4, V5). LIKE '%_%' больше не останавливает сервер (V3). Закрыты V8–V12, U3, U9, R1 для текста, диапазоны NONE, три низкие находки BHJ. Цена BLOB на примере из документации: 0.19 с против 2.32 с.
  • W1: Hash Join (outer) теряет условие ON с подзапросом или ссылкой на внешний запрос: 10 000 строк вместо 5 400, anti-join — 0 вместо 4 600. Есть на конфиге по умолчанию, HJ outer выбирается уже на 10 × 10 строк.
  • W2: BHJ останавливает сервер, если запись хэшируемой реки длиннее 64 КБ. Хватает 10 000 + 2 000 строк и конфига по умолчанию.
  • W3: LIKE 'a\%' ESCAPE '\' даёт 0 строк вместо 250. Ошибка ветки с 14.10, есть и на a3cfa97218; штатный HQbird 5.0 даёт 250.
  • W4: хранилище STAT$ от 08.11 ломает все SELECT — Column unknown STAT$BLOB_LEVELS. Миграция — 7 колонок, раздел 5.
  • W5: U1 вернулся. eqjoinsel складывает два направления: 27_eqjoin — 7 003 578 при 25 000 (на 08.11 — 94 258). W6: PREPARE у клиента WIN1251 падает на LIKE 'Мо%а'.
  • CEB не замерен: стенд dellg15 не отвечает. Тестов в коммитах нет; все три critical найдены isql-скриптами на 10 000 строк.

6Миграция хранилища STAT$ (W4)

Проверено на хранилище от a3cfa97218: после ALTER работают SELECT и REFRESH, именованные структуры сохраняются. Хранилищу старше 08.11 нужны ещё шесть колонок STAT$LEN_* (ревью 08.11, раздел 6) и STAT$SCALE SMALLINT. База CEB на dellg15 — в формате 08.11, ей нужен этот ALTER.

ALTER TABLE STAT$COLUMNS
  ADD STAT$BLOB_LEVELS BLOB SUB_TYPE BINARY,
  ADD STAT$BLOB_LEVELS_TEXT BLOB SUB_TYPE TEXT CHARACTER SET UTF8,
  ADD STAT$BLOB_AVG_PAGES DOUBLE PRECISION,
  ADD STAT$BLOB_MAX_PAGES INTEGER,
  ADD STAT$BLOB_AVG_LEN DOUBLE PRECISION,
  ADD STAT$BLOB_MAX_LEN BIGINT,
  ADD STAT$SUB_TYPE SMALLINT;
COMMIT;
ALTER DATABASE REFRESH STATISTICS;
