- **Снимок дескриптора:** у текстового BLOB теряется collation; NUMERIC/DECIMAL пишут sub type в
  STAT$CHARSET; нет снимка, если все значения слишком длинные; у OCTETS STAT$SUB_TYPE = 1 при 0 в документации. [тест]

- **Отладочные колонки:** REFRESH падает без STAT$BLOB_LEVELS_TEXT — зависимость от *_TEXT выросла. [проба]
- **LIKE без масок по CHAR** оценивается как равенство: `ch like 'ABC'` → 50 000 при 0 (результат верный). [тест]
- **Нижняя граница фрагмента** завышает несуществующие слова: `'qwertyui'` 736 при 0. [тест]
- **Уникальный текст:** граница выше максимума — одна корзина: `c >= 'k02000000'` → 20 000 при 0. [тест]

## 5. Миграция хранилища STAT$ (W4)

Проверено на хранилище от a3cfa97218: после ALTER работают SELECT и REFRESH, именованные
`CREATE EXTENDED STATISTICS` сохраняются (`tests/38a`, `38b` показывают ошибку без ALTER).

```sql
ALTER TABLE STAT$COLUMNS
  ADD STAT$BLOB_LEVELS BLOB SUB_TYPE BINARY,
  ADD STAT$BLOB_LEVELS_TEXT BLOB SUB_TYPE TEXT CHARACTER SET UTF8,
  ADD STAT$BLOB_AVG_PAGES DOUBLE PRECISION,
  ADD STAT$BLOB_MAX_PAGES INTEGER,
  ADD STAT$BLOB_AVG_LEN DOUBLE PRECISION,
  ADD STAT$BLOB_MAX_LEN BIGINT,
  ADD STAT$SUB_TYPE SMALLINT;
COMMIT;
ALTER DATABASE REFRESH STATISTICS;
```

- Хранилищу старше 08.11 нужны ещё шесть колонок STAT$LEN_* (`../2026-11-08_impropt/REVIEW.md`, раздел 5)
  и `STAT$SCALE SMALLINT`.
- Путь из документации (DROP + ADD EXTENDED STATISTICS) **теряет** именованные структуры (3 → 0).
- Хранилище новой сборки работает на a3cfa97218. Утверждение документации «после 6995f70e5a REFRESH
  не нужен» верно.
