## 5. Миграция хранилища STAT$ (V6, N1)

На стенде dellg15 сработало без потери именованных структур (`results/migrate_1108.sql`):

```sql
ALTER TABLE STAT$COLUMNS
  ADD STAT$LEN_COUNT BIGINT, ADD STAT$LEN_SUM BIGINT, ADD STAT$LEN_MIN INTEGER,
  ADD STAT$LEN_MAX INTEGER, ADD STAT$LEN_BOUNDS BLOB SUB_TYPE BINARY,
  ADD STAT$LEN_BOUNDS_TEXT BLOB SUB_TYPE TEXT CHARACTER SET UTF8;
COMMIT;
ALTER DATABASE REFRESH STATISTICS;
```

- После ADD и нового соединения SELECT работает и до REFRESH (NULL в LEN_* обрабатывается).
- Хранилищу без STAT$SCALE нужен ещё `ADD STAT$SCALE SMALLINT`.
- REFRESH на dellg15 — около 73 с.
